# 박진한 · Portfolio 2026 — React 버전

바닐라 원본(`main` 브랜치)을 React + framer-motion으로 다시 만든 인터랙티브 버전입니다.

> "박차고 나가서 진짜로 파고들어 한계까지 완성합니다."

## 특징

ReactBits 스타일 인터랙션을 직접 구현해 얹었습니다.

- **Aurora** 코발트 오로라 배경 (canvas)
- **Custom Cursor** 커서 추종 발광 원 + 요소 위 확대
- **Blur Intro** 로딩 인트로
- **Dock** 하단 플로팅 네비 (호버 확대)
- **Side Index** 좌측 세로 섹션 인덱스
- **SplitText / ShinyText / CountUp** 텍스트 애니메이션
- **TiltedCard / SpotlightCard / Magnet / ClickSpark** 마우스 인터랙션
- **Marquee** 기술 스택 무한 흐름
- **Snap Scroll** 섹션 단위 스냅
- **Project Modal** 프로젝트 상세

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
```

## 스택

React 18 · Vite · framer-motion · Pretendard · Fraunces
