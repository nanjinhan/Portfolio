# 박진한 · Portfolio 2026

IT Product Planner 박진한의 포트폴리오 웹사이트입니다.

> "박차고 나가서, 진짜로 파고들어, 한계까지 완성합니다."

## 구성

원페이지 스크롤 구조로, 하나의 이야기처럼 읽히도록 설계했습니다.

- **Hero** — 삼행시 헤드라인 + 3D 캐릭터 5종 전환 + 현재 작업 한 줄
- **Proof** — 수상·성과 (결과 먼저)
- **Journey** — 동아리 방에서 현업까지, 6개 챕터
- **Projects** — 대표 프로젝트 6개 (두괄식 아코디언)
- **Making** — 직접 만든 결과물
- **People** — 함께한 사람들
- **Direction** — 방향성
- **Contact**
